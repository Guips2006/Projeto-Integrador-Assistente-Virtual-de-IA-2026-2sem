# Projeto-Integrador-Assistente-Virtual-de-IA-2026-2sem
Repositório para entrega do trabalho do PI-ChatGPT-Crie-seu-Assistente

Este trabalho apresenta a entrega da Skill `Pokémon VGC Coach` feita para Google Gemini, uma habilidade criada para auxiliar treinadores que estão começando no cenário competitivo (VGC) de Pokémon.
A skill em questão auxilia na escolha de times, movimentos, habilidades e distribuições de pontos de estatística para os Pokémon disponíveis na Regulation M-C do jogo Pokémon Champions. É possível utilizá-la também para simulações de turnos reais e cálculos para ajudar o jogador a fazer uso da melhor estratégia possível.
